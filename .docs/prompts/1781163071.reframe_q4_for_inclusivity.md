# Request

> About the Q4 question, yes draft the improvements in the PR

(In response to a critique that Q4's hardcoded *"Python / TypeScript / Go / Rust / something else / mixed?"* phrasing made non-Python users feel like second-class citizens — Python led the list, only four languages were named, and the fallback label *"something else / mixed"* read as apologetic.)

## Reasoning

This is the small, decoupled half of the work tracked at `.docs/todos/expand-q4-language-coverage.md` (lands via the still-open `feat/bootstrap-self-application` PR). The bigger half — adding actual first-class scaffolds for C# / .NET, Java, Ruby, PHP, Kotlin, Swift, and Markdown / docs-as-code — needs each language's `.gitignore` variant, linter config, `Makefile` family, and `TRUSTED_DEV` allow addendum, which is real per-language work best contributed by someone who lives in that language daily.

The Q4 *question-text* reframing is independent of those template additions: it costs a single line edit, signals coverage gaps honestly, and explicitly invites contributions. Two changes shipped together:

1. Label changes from *Language / runtime* → *Primary language or content type* — broader scope, doesn't lead with executables.
2. Options text lists eleven named examples (Python, TypeScript, Go, Rust, C# / .NET, Java, Ruby, PHP, Kotlin, Swift, Markdown / docs-as-code) plus *"something else."* Explicitly names which of those eleven have first-class scaffolds today (Python, TypeScript, Go, Rust) and points the others at [`CONTRIBUTING.md`](../../CONTRIBUTING.md) so the path to first-class status is visible from inside the question itself.
