# Request

> I've acquired this domain name (agentic-bootstrap.md) from `register.domains` and I want to configure my GitHub page with a custom domain. What are the steps to achieve that? Ensure to search the web for the GitHub custom domain setup!

## Reasoning

The `.md` TLD (Moldova ccTLD, reads as "Markdown") is the project's brand punchline — the URL equals the title equals the artifact. Configuring it on Pages was the unblocking step for the LinkedIn launch later the same day. The exchange walked through every DNS surface (apex A, AAAA for IPv6, `www` CNAME), the GitHub Pages settings UI, and the certificate-provisioning timeline.

The architectural rationale lives in [ADR-0005](../adrs/0005-custom-domain-agentic-bootstrap-md.md).
