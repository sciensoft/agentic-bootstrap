# Request

Draft a distribution plan for sharing the context-management improvement work on LinkedIn engineering groups and adjacent channels (Hacker News, X, Reddit). Put it under `.docs/distribution/` — a new folder — and gitignore the whole folder so the plan file stays local while the `.gitignore` addition ships with the branch.

## Reasoning

User wants a private working doc that captures positioning, target channels, draft post copy, cadence, and success signals. Not a blog post to publish now — a plan the maintainer can execute against over a two-week window. Landing page is already shipped and calibrated for this audience; the distribution plan is what turns the landing page into a launch.

Gitignoring the folder (rather than just the file) means future distribution plans, campaign notes, or asset drafts can drop in without needing per-file `.gitignore` maintenance. The pattern mirrors `.docs/todos/` (indexed by directory listing) but for private working material rather than deferred work.

Contents are calibrated to match the improvements doc's voice: honest, concrete, quantitative, allergic to over-claiming. The plan explicitly warns against grand framing ("future of AI coding") and against posting everything on day 0 — the launch cadence is deliberate and low-key because that's what the material rewards.

## Consulted rules

- `workflow.md` — new artifact-producing task; prompt file + commit + push for the `.gitignore` change.
- `workflow-changes.md` — `.gitignore` change is user-visible in the sense that clones behave differently after the change (new directory silently ignored). Worth flagging in commit body.
- `workflow-todos.md` — the plan file is not a TODO (it's a private working doc, not a deferred idea); goes under `.docs/distribution/`, not `.docs/todos/`.
- `best-practices.md` (Markdown-content discipline) — heading hierarchy stable, cross-references use repo-relative paths from `.docs/distribution/`.

Not applicable: `workflow-security.md` (no security surface — private local working doc, no credentials, no execution), `workflow-metrics.md` / `workflow-testing.md`.
