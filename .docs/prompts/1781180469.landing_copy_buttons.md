# Request

> In the "Drop the file" and "Tell the agent" code blocks, add a copy item so people can easily copy and paste on their terminal!

## Reasoning

The two code blocks in the landing page's *Three steps. One file. One commit.* section show the exact `curl` command and the exact agent prompt a user needs to start the bootstrap. Without a copy button, a visitor has to triple-click, drag-select, or hand-retype them — and the displayed text carries shell decoration (`$ ` for the curl, `› ` for the prompt) plus a literal line break the user doesn't want in their paste buffer.

A one-click copy turns "I want to try this" into "it's on my clipboard" in under a second. Implementation kept minimal: vanilla JS using the modern `navigator.clipboard.writeText` API, no dependencies, no external library. The clean text to copy lives in a `data-copy` attribute on each `.codeblock`, decoupled from the syntax-highlighted display markup — so the displayed line keeps its shell-prompt decoration while the clipboard gets the bare command.

## Output

- [`docs/index.html`](../../docs/index.html):
  - **CSS** — `.copy-btn` rules with resting state (`#d4d4d8` on `rgba(255,255,255,0.04)`, matching the `.tk-d` palette already in use) and a `data-copied="true"` state that swaps to a violet checkmark on the brand's accent palette. Hover state lifts to white-on-`rgba(255,255,255,0.1)`. SVG icon swap via CSS `display: none` / `display: block` toggled by the data attribute.
  - **HTML** — Both code blocks gain `position: relative` (via the `relative` Tailwind utility) plus a `data-copy` attribute and a `<button class="copy-btn">` carrying two SVGs (copy / check). The `data-copy` value strips the `$ ` prefix from the curl line and joins the two-line agent prompt into one line so the clipboard content is paste-ready.
  - **JS** — A single `querySelectorAll('.copy-btn').forEach` in the existing bottom-of-page script block. Each button: reads `data-copy` from the parent `.codeblock`, calls `navigator.clipboard.writeText`, sets `data-copied="true"` for 1.5s, updates `aria-label` to "Copied!" during the feedback window and restores afterwards. Wraps the clipboard write in try/catch with a silent fallback so older browsers don't throw — they just don't get the copy behaviour.
