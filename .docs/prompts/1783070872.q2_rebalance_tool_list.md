# Request

Real bootstrap-run screenshot: Claude Code's picker rendered Q2 as four preset bundles — *"Claude Code only"* / *"Claude Code + Cursor"* / *"Claude Code + GitHub Copilot"* / *"All eight tools"* / *"Other"*. User's two observations:

1. **Too Claude-Code-centric.** Three of the four preset options have Claude in them.
2. **"All eight tools" doesn't make sense.** Nobody uses all eight; edge case at best.

User's directive: *"Yes, let's have 4 + others with the top 4/common Agentic tools."* + *"They should pick what they want to use, it can be 1 tool, it can be 2, or even 3 or more for a larger team. But they are the ones chosing it. We only save/keep their choice!"*

## Reasoning

The Q2 text already said *"Multi-pick from the Supported tools table"* — but in practice the agent rendered its own preset bundles anyway, presumably because the picker primitive it was reaching for (Claude Code's `AskUserQuestion`) works better with a small number of curated options than with 8 individual checkboxes. The fix is to be explicit at the Q2 spec level: this is a multi-select of individual tools, and any preset-bundle rendering is wrong.

Two shape choices baked into the rewrite:

- **Naming the top 4 by adoption** so the agent has a signal for which four to surface first if the picker supports grouping or a *show more* expansion. Chosen top 4: **Claude Code · Cursor · GitHub Copilot · Windsurf**. Other 4: **Aider · Codex CLI · OpenCode · Continue.dev**.
- **Ordering within the top 4** is alphabetical (C · C · G · W). An earlier draft reordered to put Cursor first and Claude Code last on the theory that Claude Code's leading position was part of the problem; user clarified the actual concern was three-of-four presets centering Claude Code (i.e. the *bundle* structure), not Claude Code appearing at all in the primary group. Alphabetical is the honest, uncontroversial default.

The rewrite also explicitly forbids the specific bad shapes (*"e.g. 'Claude Code + Cursor', 'All eight tools'"*) so a future agent reading Q2 has the pattern to refuse if it's tempted to invent bundles.
