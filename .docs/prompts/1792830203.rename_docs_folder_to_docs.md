# Rename `.docs/` → `docs/` in the bootstrap generator

## Prompt

> Okay, let's do a simple change! Right now the bootstrap creates a folder called `.docs/` for the artifacts it generates. However, I want it to change to `docs/`. It must be backwards compatible, meaning existing bootstrapped repos should get the refactor to `docs/`.

Follow-up:

> It's inside @AGENTIC-BOOTSTRAP.md

> That's the main entrypoint

## Reading

Scope is the bootstrap generator file `AGENTIC-BOOTSTRAP.md` plus its direct housekeeping (version header, `CHANGELOG.md`, the lint script's comment). The self-applied artifacts in this repo's `.docs/` (ADRs, prompts, todos, security) and the three case-study projects under `examples/` stay as they are — those are existing bootstrapped repos that will migrate the first time someone re-runs the new bootstrap version on them. That path is what "backwards compatible" asks for.

## What changed

- All 96 occurrences of `.docs/` → `docs/` in `AGENTIC-BOOTSTRAP.md` (template text, prose, decision matrix, Template Index, rule-file templates, Part 4 and Part 5 content).
- New `Docs-folder migration` bullet in Step 0 (sibling to the existing `.claude/rules/` → `.agents/rules/` legacy migration). Detects `.docs/<sub>/` presence, `git mv`s each sub-directory into `docs/`, flags conflicts, rewrites text references across the usual trigger-index files.
- Step 1 collision check and the clean-wipe backup list extended with the legacy `.docs/adrs/` and `.docs/todos/` so first-time mode still flags leftovers from a pre-rename bootstrap.

- `CHANGELOG.md`: new `[2026-10-24]` entry under *Changed* describing the rename and the auto-migration.
- `scripts/lint_bootstrap.py`: one comment-only path update (`.docs/prompts/…` → `docs/prompts/…`).
- Template Index offsets shifted by +6 to account for the new migration bullet.
