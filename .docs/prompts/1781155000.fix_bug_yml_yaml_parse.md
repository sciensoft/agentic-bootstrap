## Reasoning

GitHub silently skips issue-form templates it can't parse — no warning surfaced, just a missing card. Two of three templates rendered, which proved the PR had merged but bug.yml specifically was broken. The `description` field for `bootstrap-version` contained the literal text `<!-- bootstrap-version: YYYY-MM-DD -->`. In a plain YAML scalar, the `: ` (colon + space) inside that comment is interpreted as a key separator, breaking the document.

Lesson captured in the Markdown-content best-practices: validate YAML locally before push — see [`.agents/rules/best-practices.md`](../../.agents/rules/best-practices.md) §3 (Code fences) for the rule.

## Output

- [`.github/ISSUE_TEMPLATE/bug.yml`](../../.github/ISSUE_TEMPLATE/bug.yml): wrapped the `bootstrap-version` field's description in single quotes so the content is parsed as an explicit string scalar.
