# Request

> Shouldn't we change `BOOTSTRAP_CHANGELOG.md` to `CHANGELOG.md` only?

## Reasoning

The `BOOTSTRAP_` prefix was a vestige of single-file-project days. The whole repo IS the bootstrap; the prefix is redundant. `CHANGELOG.md` is the universal convention — GitHub auto-detects it for the Releases sidebar, contributors look there by reflex, and the bootstrap itself scaffolds a `CHANGELOG.md` for downstream projects. The repo not following its own convention was a credibility smell.

The decision lives at [ADR-0003](../adrs/0003-standardize-on-changelog-md.md); the related Always-Sacred policy review is at [ADR-0006](../adrs/0006-keep-changelog-md-always-not-opt-in.md).
