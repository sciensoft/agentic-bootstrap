# Request

> Let's do "The Index's drift safeguard (re-grep if an offset doesn't land) keeps smart-agent reads correct in the meantime; the .docs/todos/lint-template-index-offsets.md follow-up will catch this kind of drift automatically once shipped."

(Implementing the follow-up tracked at `.docs/todos/lint-template-index-offsets.md` — adding a fifth lint check that validates the Part 4 Template Index stays in sync with actual `### Template:` heading positions in `AGENTIC-BOOTSTRAP.md`.)

## Reasoning

ADR-0008 added the Template Index to let capable agents skip irrelevant templates via offset reads (~80k → ~25k scaffold-time tokens). The Index ships with a runtime drift safeguard — if an offset doesn't land on a `### Template:` heading, the agent re-greps — but that's a band-aid that only triggers when an agent actively hits stale data. Silent waste was the failure mode the Index couldn't catch on its own.

Five passes through Part 2 since the Index landed (Q4 reframe, Q5 compression, Q2+Q3 compression in flight) have made the drift problem real: every line-shifting edit invalidates ~80 offsets. The drift safeguard kept the world working, but the offsets accumulated debt.

Building the lint check enforces sync in CI: a maintainer who edits Part 4 (or anything earlier in the file) gets immediate failure with a precise diff naming which rows are stale and how to fix them. The cost is one Python function and a run-time of well under a second.

## How the check fails (failure-mode demo)

If a future edit shifts Part 4 line numbers without updating the Index, CI will produce:

```text
lint_bootstrap: FAIL (1 finding(s))
  - template_index: 78 offset mismatch(es) — re-grep `^### Template:` in AGENTIC-BOOTSTRAP.md to refresh the table
  - template_index: row 1 (`CLAUDE.md`): index says 496 → 524, actual is 512 → 540
  - template_index: row 2 (`.agents/rules/workflow.md`): index says 525 → 967, actual is 541 → 983
  - template_index: row 3 (`.agents/rules/workflow-todos.md`): index says 968 → 1072, actual is 984 → 1088
  - template_index: ...and 75 more mismatches (showing first 3)
```

The maintainer runs `grep -n "^### Template:" AGENTIC-BOOTSTRAP.md`, derives the corrected ranges, and patches the table. Or, more practically, runs the same in-place refresh script used in this PR (worth promoting to `scripts/refresh_template_index.py` as a future helper — captured implicitly; small enough that a maintainer can paste it inline for now).
