## Reasoning

Cuts 1–3 + MCP shipped the context-management improvements for **new** projects. Existing projects still carry the pre-Cut-1 brief shape: `AGENTS.md`'s `## Rules` section is a bullet list of every rule (treated as always-loaded reference — the failure mode Cut 1 fixed), and `CLAUDE.md` `@`-imports every rule file. Sacred re-run policy (Part 3 matrix) intentionally protects those files from silent rewrites — which means the 90% context cut never lands on existing projects until someone hand-migrates. This is the gap the migration closes without breaking the Sacred contract: nothing moves unless the user explicitly accepts the migration prompt.

Folding into Step 0 (rather than a separate step number) is the right structural choice — Step 0's job is already run-mode detection and migration handling (there's a legacy-layout migration bullet already, `.claude/rules/` → `.agents/rules/`). Brief-shape migration is another branch of the same detection logic. Detection is content-based, not version-based, so a bootstrap-version bump is optional and a user's hand-edits are not a barrier.

Delivery constraint: no external scripts. Everything runs inside the agent's read-and-execute loop over `AGENTIC-BOOTSTRAP.md`. The migration is instructions, not a helper.
