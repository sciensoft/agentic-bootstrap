# Request

All external links on `docs/index.html` (`<a href="https://...">`) should open in a new tab so readers don't lose the landing page when they click through to GitHub, examples, quickstart, changelog, etc. Internal in-page anchors (`<a href="#...">`) should stay in the same tab — normal single-page navigation.

## Reasoning

Landing page is a marketing surface; every click that navigates away drops the visitor's context. Opening external destinations in a new tab is the standard convention for docs sites, GitHub-adjacent landing pages, and anything where the reader is likely to want to return. The `rel="noopener noreferrer"` companion is the security-conscious default — `noopener` prevents the destination from reaching `window.opener`, `noreferrer` also hides the referrer header.
