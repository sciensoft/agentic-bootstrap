# Request

Update `docs/index.html` to advertise the context-management improvements shipped on this branch, add a subscription-cost banner, remove `Continue.dev` (discontinued — merged into Cursor), and convert the hero CLI mockup and file-tree section into per-agent tabs so readers see the honest single-agent scaffold rather than a misleading multi-agent "kitchen sink" listing.

## Reasoning

The context-management overhaul on this branch (Cuts 1–3 + MCP + Migration + Gap 2) is a substantial improvement worth advertising — the "always-loaded rule set" figure the landing page implied has dropped from ~47k tokens to ~4.5k measured. The current *Runtime footprint* section is stale (says `5-15k tokens every session after`), and the mechanism (trigger index, mechanical enforcement) is genuinely differentiating; both belong on the page.

The scaffold cost is real — a smart-agent bootstrap reads ~25k tokens, a naive one ~80k. On per-token API billing that adds up to several dollars; on fixed-rate subscriptions it's absorbed. A thin banner naming that trade-off is more honest than letting a user discover the cost on the first invoice.

The current hero CLI mockup shows an `Agents used? Claude, Cursor, Codex` answer and a "Scaffold written" list that includes adapters for every one of `CLAUDE.md`, `.cursor/rules/`, `.aider.conf.yml`. A first-time reader looks at that and thinks all those files land regardless of their pick. That's the misleading experience the user flagged — a tabs-driven mockup shows the honest single-agent case, and tabs on the file tree carry the same discipline further down the page. Tab state is shared via JS: clicking a tab in either place switches both.

Continue.dev removal is straightforward — the product has been discontinued and its team joined Cursor. Five hits in the page: meta description, works-with strip, how-it-works copy, file-tree line (moot after tabs), permission-postures paragraph.

## Consulted rules
