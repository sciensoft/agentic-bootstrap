# Request

Fix two related confusions on the landing page's Doctor mode card:

1. The link URL points at the top of `AGENTIC-BOOTSTRAP.md` with no anchor — clicking dumps the reader at line 1, and they have to hunt for the Doctor mode section.
2. The visible text on the card says *"See doctor-mode spec →"*, but Ctrl+F for `doctor-mode` in the linked file finds nothing — the bootstrap heading is `#### Doctor mode (audit-only — no writes)`, spaces and parenthetical, not the hyphenated slug form.

Fix: simplify the bootstrap heading, add the anchor to the URL, align the card text with the heading form.

## Reasoning

The parenthetical in the bootstrap heading (`(audit-only — no writes)`) is duplicated verbatim in the first sentence of the section body — dropping it from the heading loses zero information and gives GitHub a clean slug to point at. With `#### Doctor mode`, the GitHub-auto-generated anchor becomes `#doctor-mode`, which is exactly the term the landing page card uses. Ctrl+F on the linked page then works, and the card link jumps the reader to the section instead of the top of the file.

Landing-page card text updated in the same beat to read *"Read the Doctor mode section →"* — matches the heading form and the URL slug's semantic meaning, and reads better than the bare *"spec"* framing.
