## Reasoning

Investigation confirmed:

1. **The bootstrap already supports C# / Java / Ruby / PHP / Kotlin / Swift / Markdown / anything-else** via the **generic fallback variant** that dispatches when `LANG ∉ {Python, TypeScript/Node, Go, Rust}`. Q4's question text already lists those languages as valid examples (line 355 of `AGENTIC-BOOTSTRAP.md`). The fallback covers `.gitignore`, manifest + test scaffold, linter / formatter configs, and `Makefile`.
2. **First-class scaffolds** — curated `.gitignore` + linter + `Makefile` + manifest stub + `TRUSTED_DEV` allow addendum — exist only for Python / TypeScript / Go / Rust.
3. **Adding first-class scaffolds for C# / Java / etc. is real work** — multi-template addition per language, tracked in `.docs/todos/expand-q4-language-coverage.md`. Out of scope for this PR.

So the gap was **landing-page copy**, not bootstrap functionality. The Polyglot tile's prior text named only the four first-class languages and read as if everything else was unsupported. The actual story is: *"we have curated scaffolds for 4 languages; we have generic scaffolds for everything else; the `best-practices.md` web refinement works for any language you pick."*

Tone choices for the new tile copy:
- Lead with the four first-class languages — that's the strongest claim and it's honest.
- Name 7 languages in the "generic scaffolds for everything else" list (C# / .NET, Java, Ruby, PHP, Kotlin, Swift, Markdown) — matches what Q4's example list carries; mirrors `QUICKSTART.md` line 23 which already does this correctly.
- Add *"anything you pick"* — signals open-endedness without listing every language.
- Call out that `best-practices.md` refinement works *regardless of language* — the most valuable piece of the bootstrap and the one that was easy to miss when the tile led with four-named-languages framing.

QUICKSTART.md already handles this correctly (line 23 explicitly names all 11 languages from Q4); README.md doesn't mention specific languages anywhere. Only `docs/index.html` line 711 needed updating.
