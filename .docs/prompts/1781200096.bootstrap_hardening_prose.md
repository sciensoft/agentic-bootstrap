## Reasoning

Five small prose additions, all positioned for visibility against the observed failure pattern — *jump straight to file writes, skip the interview, treat `{{PLACEHOLDER}}` as content rather than as a substitution token*. The agent that failed read the top of the file most reliably; the additions sit at the top.

Why these five and not more:

1. **STOP callout** above Part 1 — the *single most visible spot in the document* for an agent that skims. Reframes the file as a playbook, not a file catalogue.
2. **Anti-patterns sub-section** inside *How to use* — names the failure modes explicitly so the agent has a pattern to refuse if its training prior pulls it toward them.
3. **Model-capability note** alongside the anti-patterns — honest framing: some models can't reliably hold an 80-template orchestration. Listing the model classes that can ("Claude Sonnet / Opus, GPT-4 class, Gemini 1.5 / 2.x, full DeepSeek-V3, Qwen 2.5 Coder 32B+") tells the operator what to pick without insulting models that don't make the cut.
4. **Step 0 imperative opener** — *"Your first action: read this entire file. Do not write anything yet."* leads the section. The previous opener (*"The bootstrap is idempotent..."*) buried the most important instruction. Weak models read first lines of sections most reliably.
5. **Step 4 gate check** — explicit dependency on Steps 0–3 right at the section opener, before the existing performance tip. The Template Index (#11) made it possible for capable agents to jump directly to Part 4 templates; if an agent navigated there *without* doing the interview first, it would find templates full of `{{PLACEHOLDER}}` tokens it has no values to substitute. The gate-check catches this.

A 6th item from the original proposal — a Doctor-mode `{{` check that surfaces interrupted bootstraps post-hoc by scanning scaffolded files for literal `{{...}}` — is deferred to a follow-up PR. It's a separate concern (Doctor mode runs from the playbook, not from `scripts/lint_bootstrap.py`) and the prose hardening above is the first-line defence.
