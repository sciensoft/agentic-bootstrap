# Reach out to one tool maintainer directly

**Area**: distribution / endorsements

**Refs**:
- [`.docs/adrs/0004-single-file-agent-executable-delivery-model.md`](../adrs/0004-single-file-agent-executable-delivery-model.md)

## Context

Endorsement from a tool maintainer carries weight that no awesome-list entry can match. Candidates, in rough order of expected DM-response rate:

- **Paul Gauthier (Aider)** — DM short note: *"We built a single-file bootstrap that writes an `.aider.conf.yml` adapter pointing at AGENTS.md. Would value your eyes on the template."*
- **hesreallyhim** (awesome-claude-code curator) — combine the outreach with the awesome-list submission.
- **Anthropic Claude Code team** — via direct contact or the AAIF channel.

Pick one to start. Quality of the outreach matters more than breadth — a single thoughtful DM beats five blast messages.

## Deferred because

Best reached after the project has at least one external dogfooding example, so the conversation is *"here's a thing that works for users"* rather than *"here's a thing I built."*

## Revisit when

After the first external project's "I tried it" Discussion or GitHub Issue lands.
