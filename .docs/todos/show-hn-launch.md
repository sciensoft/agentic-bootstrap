## Context

Hacker News tolerates exactly one "Show HN" per project. The `.md` TLD is the hook — it earns the click on its own. Lead with the domain in the title:

> Show HN: agentic-bootstrap.md — single-file bootstrap for any AI coding agent

Timing: Tuesday or Wednesday morning ET. Warm with existing LinkedIn traction, a few real GitHub stars, and at least one external project that's been bootstrapped (so the comment thread has an "I tried it" voice early). Drop the 90-second demo recording in the first comment.

## Deferred because

The one-shot can't be wasted. Needs both the demo asset (separate TODO) and at least one awesome-list acceptance to give the post supporting evidence. Firing too early burns the slot.

## Revisit when

All three preconditions met: (a) demo asset recorded, (b) at least one awesome-list accepted the entry, (c) at least one external dogfooding example exists in Discussions or as a downstream GitHub repo. Earliest fire date: 2026-06-23 (two weeks post-LinkedIn).
